# Mortgage Discount Points Break-Even Planner

Calculates whether purchasing mortgage discount points is financially worthwhile by computing monthly savings, break-even timeline, and NPV of all future savings.

## Key Features

- Inputs: loan amount, interest rates with and without points, number of points (each = 1% of loan), loan term, and NPV discount rate
- Computes monthly payment comparison, points cost, break-even month, total interest saved, and NPV of savings at a configurable discount rate
- Visual break-even timeline bar that turns green (within term) or red (beyond term)
- Cumulative savings comparison table at Year 1, 3, 5, 10, and full term with net gain/loss after points cost
- Auto-calculates on page load with sensible defaults; Enter key triggers recalculation from any input
